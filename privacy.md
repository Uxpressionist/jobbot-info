# Jobbot Privacy Policy

Last updated: October 26, 2026

Jobbot is a personal automation tool built and used by Godfrey Oboh.

## What data Jobbot accesses
Jobbot accesses only the Google account data of its owner, and only the
data needed to perform its automated tasks.

## How data is used
Data is used solely to run the automation. It is not sold, shared with
third parties, or used for advertising.

## Storage
Authorization tokens are stored as encrypted GitHub Actions secrets.
Jobbot does not keep any other copy of Google user data.
